# HOOYA — خانه مد هویا

دموی صفحه اصلی فارسی و راست‌به‌چپ برای پوشاک روایت‌گر ایرانی، با لوگوی اصلی هویا و چیدمانی الهام‌گرفته از مرجع Dior Beauty.

## اجرا

نیازی به نصب وابستگی نیست. با Node.js دستور زیر را اجرا کنید:

```sh
node preview.mjs
```

سپس `http://127.0.0.1:4180` را باز کنید. داشبورد در `http://127.0.0.1:4180/admin/` قرار دارد. برای دریافت کاتالوگ باید سایت را با سرور HTTP باز کنید؛ بازکردن مستقیم فایل HTML کافی نیست.

## انتشار

GitHub Pages از شاخه `main` و پوشه `/docs` منتشر می‌شود. فایل‌های HTML، CSS و JavaScript و تصاویر همگی داخل `docs` قرار دارند و مسیر دارایی‌ها نسبی است.

## امکانات

- منوی کشویی، جست‌وجوی لباس و فیلتر دسته‌بندی
- کشف مجموعه بر اساس شاهنامه، اسب، روایت اقوام و نمادهای ایران
- نمایش داستان لباس، اندازه پیشنهادی و سبد انتخاب‌های محلی
- نمایش سازگار با موبایل و پشتیبانی از کاهش حرکت
- اسلایدر اصلی با سه مجموعه، حرکت خودکار شش ثانیه ای، توقف، کلیدهای جهت و انتخاب اسلاید؛ در حالت کاهش حرکت، پخش خودکار خاموش است.
- صفحه مستقل `about.html` برای «درباره من»، با متن مبتنی بر معرفی برند و تصویر جزئیات دوخت؛ اطلاعات شخصی طراح هنوز در اختیار نیست.
- متن های فارسی ویترین و داشبورد بدون اعراب هستند.
- صفحه `contact.html` آدرس دو محل فروش حضوری، جستجوی آدرس در نقشه، کپی آدرس و راه های ارتباط را نمایش می دهد. شماره واتساپ ارائه شده در `docs/contact.json` به صورت بین المللی بدون علامت `+` نگهداری می شود و لینک مستقیم گفتگو را فعال می کند.

تصاویر ویترین و گالری‌ها، عکس‌های واقعی ارائه‌شده هویا هستند. شش محصول هرکدام سه تصویر بهینه‌شده WebP دارند. در گالری پرستو، تصویر سوم یک برش نزدیک از عکس واقعی دوم است؛ عکس‌های بلبل که داخل پوشه پرستو هم بودند در این محصول استفاده نشده‌اند. اصل فایل‌ها تغییر نکرده است. اندازه‌ها همچنان پیشنهادی‌اند و قیمت و موجودی تأییدشده‌ای ثبت نشده؛ ثبت سفارش و پرداخت فعال نیست. سبد فقط در مرورگر ذخیره می‌شود.

گالری هر لباس از فیلد اختیاری `images` خوانده می‌شود. تصویر اول با فیلد `image` یکسان است؛ ویرایش مشخصات محصول در داشبورد، عکس‌های دیگر گالری را حفظ می‌کند. مسیر عکس‌های این مجموعه زیر `docs/assets/products` است و در ویترین و پیش‌نمایش داشبورد درست باز می‌شود.

فونت Vazirmatn از مخزن رسمی rastikerdar/vazirmatn دریافت شده و فایل مجوز OFL آن در `docs/assets/Vazirmatn-OFL.txt` قرار دارد. لوگو و محتوای برند متعلق به صاحبان آن‌هاست.

## داشبورد محصولات

نشانی منتشرشده: https://atikia92-afk.github.io/hooya-mode/admin/

۱. «محصول جدید» را بزنید و نام، کد، دسته، قیمت به تومان، موجودی کل، اندازه‌ها، داستان، رنگ‌ها و تصویر را وارد کنید. تصویر از دستگاه به WEBP بهینه تبدیل می‌شود؛ لینک مستقیم HTTPS نیز پذیرفته است.
۲. محصول را به‌صورت پیش‌نویس، منتشرشده یا بایگانی ذخیره کنید. ذخیره در این مرحله محلی و وابسته به همین مرورگر است. برای نگهداری مستقل، از دکمه پشتیبان در بالای کاتالوگ استفاده کنید.
۳. «انتشار تغییرها» فهرست تغییرها را نشان می‌دهد. کلید fine-grained GitHub متعلق به صاحب مخزن را فقط برای مخزن `hooya-mode`، با مجوز `Contents: Read and write` وارد کنید. آن را در چت ارسال نکنید. کلید فقط برای همان درخواست در حافظه موقت صفحه استفاده و پس از تلاش از ورودی پاک می‌شود؛ در localStorage یا فایل ثبت نمی‌شود.
۴. دکمه ارسال، فایل `docs/products.json` در شاخه `main` را با GitHub Contents API به‌روزرسانی می‌کند. GitHub Pages معمولا برای نمایش نسخه تازه چند دقیقه زمان نیاز دارد. تأیید ثبت در GitHub به معنی تأیید اتمام ساخت Pages نیست.

مرجع مجوز و API: https://docs.github.com/en/rest/repos/contents#create-or-update-file-contents

داشبورد یک صفحه ایستا است و خود صفحه ورود کاربری ندارد؛ اطلاعات عمومی کاتالوگ را می‌خواند، اما بدون کلید معتبر هیچ تغییری در سایت نمی‌دهد. اطلاعات محرمانه، قیمت خرید، یادداشت داخلی و کلید دسترسی را در فیلدهای محصول نگذارید: کل کاتالوگ شامل پیش‌نویس‌ها در مخزن عمومی قابل خواندن است. پیش‌نویس و بایگانی فقط از نمایش در ویترین حذف می‌شوند.

تغییر هم‌زمان کاتالوگ در دستگاه دیگر، با مقایسه نسخه پایه و SHA پیش از نوشتن متوقف می‌شود. در صورت تعارض، از تغییرهای محلی پشتیبان بگیرید، نسخه جدید را در مرورگر دیگری باز کنید و تغییرهای موردنظر را تطبیق دهید. تغییرهای یک ویرایشگر به‌طور خودکار با ویرایشگر دیگر ادغام نمی‌شوند.

قیمت و موجودی محصولات نمونه نامشخص است. موجودی فعلی یک عدد برای کل محصول است و به تفکیک اندازه مدیریت نمی‌شود. سبد، پرداخت و سفارش همچنان نمایشی‌اند. کاتالوگ حداکثر ۲۵۰ محصول و ۹۰۰ کیلوبایت دارد؛ برای کاتالوگ تصویری بزرگ‌تر از لینک تصاویر استفاده کنید.

آزمون قرارداد داده و کنترل انتشار (بدون وابستگی): `node --test tests/catalog.test.mjs`
