# Typography sources

The demo uses IRANYekan, with the same five static weights declared in the DigiStyle stylesheet inspected on 2026-11-19: 300, 400, 500, 700 and 800. The logo is an image and is unaffected by this typography change.

Source stylesheet: https://www.digistyle.com/_next/static/css/a2f44109d1913716.css

The web-font binaries are stored locally below `docs/assets/fonts/iranyekan/`, so rendering does not depend on third-party font requests.

- `iranyekanweblight.woff2`: https://www.digistyle.com/assets/fonts/iranyekan/woff2/iranyekanweblight.woff2
- `iranyekanwebregular.woff2`: https://www.digistyle.com/assets/fonts/iranyekan/woff2/iranyekanwebregular.woff2
- `iranyekanwebmedium.woff`: https://www.digistyle.com/assets/fonts/iranyekan/woff/iranyekanwebmedium.woff
- `iranyekanwebbold.woff2`: https://www.digistyle.com/assets/fonts/iranyekan/woff2/iranyekanwebbold.woff2
- `iranyekanwebextrabold.woff`: https://www.digistyle.com/assets/fonts/iranyekan/woff/iranyekanwebextrabold.woff
